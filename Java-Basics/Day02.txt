Naming Convention
    1. PascalCase - use for class / interfaces
            example - AppleAndBanana
    2. camelCase - use for Method/variable
            example - totalFruits
    3. UPPER_SNAKE_CASE - use for constant
            example - MAX_NUMBERS
    4. lowercase - use for package
            example - com.example.variety


Data and operators
Variables - variable is a box in the memory that stores a value.
            And we are declare which type of value box are stores.

            dataType variableName = value;

in variable are complete in three steps
    Declaration - creates the variable - int x;
    int age;
    age = 10;
    initialization - give it the first value - x = 4;
    Assignment  - change the value later - x = 10;

kind of variables

    1. local variable - inside the method or block      you must assign it before use
    2. instance variable - inside a class, outside the method   0/false/null
    3. static variable - inside a class with static     0/false/null

Data type
    generally it is two types
        1. primitives types - prebuild
        2. Non-Primitives types - created by coder
